## Этап 3. ConfigMap и Secret

Вынеси конфигурацию из манифестов. URL Redis и имя базы — в `ConfigMap`. Пароль Postgres и ключи — в `Secret`. Подключи их двумя способами: через `envFrom` и через volume-mount файлом.

**Приёмка:**

- в манифестах Deployment не осталось ни одного хардкоженного пароля
- смени значение в ConfigMap и объясни, подхватит ли его уже запущенный под; для env и для смонтированного файла ответ разный

```bash
kubectl port-forward service/api 8000:8000
```

Зашел через браузер сначала на api а потом на swagger fastapi проверил что теперь readyz работает

Изменил значение в конфиг мапе, readyz не отвалился, а значит значение в env не изменилось

Значения ConfigMap, переданные через envFrom, становятся переменными окружения при создании контейнера. Изменение ConfigMap не изменяет переменные окружения уже запущенного процесса — под необходимо пересоздать. Если ConfigMap подключён как обычный volume, Kubernetes обновляет смонтированный файл в работающем поде без его пересоздания. При этом само приложение должно уметь перечитывать файл, чтобы использовать новое значение.
